CoreFi: A Core Calculus for Embedded Systems with Bounded Shared-Memory Channels

A CSP-derived calculus whose channels behave as embedded practice requires: a full buffer drops, an empty one blocks. Components orchestrate communication and computation events, and are composed by the kernel's scheduling rule, instantiated on seL4 Microkit. Every well-formed system is deadlock-free and deterministic.
