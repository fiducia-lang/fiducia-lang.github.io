Security patterns

A library of security design patterns on seL4, each with an architecture diagram, a C implementation and, where available, its Fiducia specification.

Network Data Diode

One-way flow between networks through a trusted forwarder that never replies.

Virtualisation · Fiducia source

Linux VM Data Diode

Ethernet-level diode between two full Linux guests on seL4.

Covert channels · Fiducia source

NRL Pump

Buffers and jitters messages to close the timing channels a plain diode leaves open.

Multi-level security · Fiducia source

MLS Email Guard

Sanitised downgrade from SECRET to OFFICIAL; upgrades always blocked.

Content policy · Fiducia source

Clipboard Guard

Checks clipboard content against a keyword policy before it crosses domains.

Media sanitisation · Fiducia source

JPEG Metadata Filter

Strips EXIF, GPS and comments inline; only pixel data crosses.

Trusted input · C only, Fiducia coming

Keyboard Switch

Routes keyboard input to one security domain at a time, flushing buffers on every switch.

Trusted display · C only, Fiducia coming

Framebuffer Compositor

A trusted compositor draws unspoofable borders around isolated per-domain framebuffers.

Residual data · C only, Fiducia coming

Domain Switch Flush

Zeroes shared workspace buffers on every domain switch, closing residual-state channels.
